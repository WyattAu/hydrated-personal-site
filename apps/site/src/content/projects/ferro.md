Self-hosted file storage without the operational burden of enterprise suites. One binary, your hardware, your files.

## Key Features

- **Multi-protocol access** — WebDAV for native OS mounts plus an S3-compatible API for tooling
- **Identity built in** — OIDC login instead of bolted-on auth
- **Full-text search** — Index and find document contents, not just filenames
- **WASM components** — Client-side acceleration where the browser can do the work
