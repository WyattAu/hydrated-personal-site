Polyfont is an editor plugin that enables dynamic font switching for monospace code blocks. Map different programming languages to different monospace fonts for a personalized coding experience.

## Key Features

- **Per-Language Fonts** — Assign different monospace fonts to different programming languages
- **Hot Switching** — Automatically switch fonts when changing between file types
- **Custom Mappings** — Define your own font-to-language configuration
- **Lightweight** — Minimal performance impact on editor responsiveness
