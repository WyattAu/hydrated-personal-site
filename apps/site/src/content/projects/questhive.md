QuestHive is a structured knowledge engine designed to make infrastructure documentation and operational knowledge interconnected and actionable. It transforms static documentation into a living, searchable knowledge graph.

## Key Features

- **Knowledge Graph** — Interconnected documentation with automatic relationship discovery
- **Infrastructure Context** — Link documentation to specific services, configs, and runbooks
- **Search Engine** — Full-text search with semantic understanding across all knowledge
- **API-First** — Headless API for integration with existing DevOps workflows
