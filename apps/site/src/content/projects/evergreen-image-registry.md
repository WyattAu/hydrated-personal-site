Evergreen Image Registry provides community-maintained long-term support Docker base images. These images are designed for production container deployments with reproducible builds, auditable layers, and automated security patching.

## Key Features

- **Long-Term Support** — Guaranteed security patches and updates for base images
- **Distroless Options** — Minimal attack surface with Google's distroless base images
- **Automated Patching** — CI/CD pipeline for automated vulnerability fixes
- **GHCR Hosting** — Published to GitHub Container Registry for easy integration
