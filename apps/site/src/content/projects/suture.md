Suture is a Rust library providing composable primitives for programmatic code analysis, AST manipulation, and source code transformation. It enables surgical precision in code refactoring and automated code stitching operations.

## Key Features

- **Composable Primitives** — Build complex transformations from simple, reusable pieces
- **AST Manipulation** — Direct access and modification of abstract syntax tree nodes
- **Source Transformation** — Generate clean, formatted output from modified ASTs
- **Surgical Refactoring** — Precise, targeted code modifications with full context awareness
