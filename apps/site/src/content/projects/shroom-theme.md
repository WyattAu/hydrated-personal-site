Shroom is a VSCode theme built around the Monaspace font family, providing dynamic font switching for monospace code. Supports multiple Monaspace variants for a fully customizable editor typography experience.

## Key Features

- **Monaspace Integration** — Optimized for Monaspace Neon, Argon, Xenon, Krypton, and Radon variants
- **Dynamic Font Switching** — Toggle between font variants within the editor
- **Syntax Highlighting** — Custom color schemes designed to complement each Monaspace variant
- **Consistent Typography** — Cohesive font sizing and spacing across all editor elements
