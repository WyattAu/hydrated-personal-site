# Projects — Wyatt Au

Open-source projects and technical work by Wyatt Au: Rust crates, WASM
quantitative widgets, MCP servers, and the intelligence dashboard you are
reading.

## What projects are featured?

- **plychart** — custom Rust/WASM charting library with pan and zoom
  powering every chart on this site.
- **estate crates** — webhookkit (idempotent webhooks), throttle-kit
  (rate limiting), otelkit (OpenTelemetry composition) and more,
  published on crates.io.
- **MCP servers** — native Rust implementations (GitHub, filesystem,
  web search, memory) used across the development estate.
- **hydrated personal site** — Astro 5 + SolidJS 1.9 + Rust/WASM
  intelligence dashboard, deployed on Cloudflare Pages and Workers.
